A Next.js + TypeScript storefront built with SCSS. This repository contains a component-driven, responsive product listing and detail UI suitable for an online sports shop.

Tech Stack: - Next.js - TypeScript - SCSS (modules) - React

Features: - Responsive, mobile-first layout - Component-based UI (product cards, hero, flash sale, reviews) - Product listing and detail pages - SCSS modules and shared styles - App Router structure for SEO-friendly routes

#Getting Started

Install dependencies and run the dev server:
Open http://localhost:3000 in your browser.

Edit the App

Start editing the main page at page.tsx.
Major UI pieces live under components (home, layout, ui).
Product data is in data.ts.

#Build for Production
npm run build
npm run start

Deploy to any Node-compatible host or container platform (no provider-specific instructions included).
